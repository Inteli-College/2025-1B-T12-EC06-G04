# Instaladores

Para facilitar a instalação da aplicação, foram criados instaladores, para Windows e Linux, visando garantir maior flexibilidade e facilidade na instalação, além de ter capacidade para ser executado em qualquer computador com Windows ou Linux.

## Windows

Para instalar o aplicativo desktop no Windows, basta acessar o caminho:

```
/src/app-rust/installers/14_Bis_Installer.exe
```

Onde você vai encontrar o arquivo 14_Bis_Installer.exe, do qual consiste em um arquivo executável, capaz de instalar a aplicação desktop em computadores que possuem o Windows como sistema operacional.

## Linux

Para instalar o aplicativo desktop no Linux, basta acessar o caminho:

```
/src/app-rust/installers/14Bis_Installer.tar.gz
```

Onde você vai encontrar o arquivo 14Bis_Installer.tar.gz
Agora, você deve extrair o arquivo, do qual possui um arquivo executável com o instalador dentro da pasta extraída, ao executá-lo, é possível instalar a aplicação desktop em computadores que possuem o Linux como sistema operacional.
