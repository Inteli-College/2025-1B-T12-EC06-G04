## Fonte de dados
- Unidade de Memória Externa: fornece imagens e metadados.

## 1. Criação do projeto
1. Iniciar projeto.
2. Preencher informações (nome, local, data, responsáveis).
3. Selecionar imagens de fissuras.

## 2. Visualização e revisão
1. Processamento automático das imagens (IA).
2. Exibição das imagens e de suas classificações.
3. Revisão/correção das classificações pelo usuário.

## 3. Geração de relatórios
1. Geração automática do relatório.
2. Visualização do relatório.
3. Exportação nos formatos MD, DOCX ou PDF.

## Fluxo resumido
Importar dados → configurar projeto → processar imagens → revisar → gerar e exportar relatório.
